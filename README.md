# Laboration 4, DT071G - C# för Machine Learning
Detta är en laboration i _Webbutveckingsprogrammet_ på Mittuniveristetet.

## Syfte
Syftet med laborationen är att efter genomförd laboration kunna använda C# och ML.NET för att kunna använda modeller och skapa lösningar för att hantera enklare klassificeringsproblem.

 ## Uppgifter
Uppgiften består av att:
 * Bygga en konsolapplikation med supervised learning,
 * Applikationen ska göra förutsägelser om överlevnad utifrån dataset,
 * Applikationen ska fråga efter relevanta features som är viktiga för en bra förutsägelse,
 * Datasetet ska delas upp i tränings- och testdata
